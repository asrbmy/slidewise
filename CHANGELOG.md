# Changelog

## 1.2.0
- Scatter charts (Category column = X values), data labels on all chart types except pie, horizontal/vertical axis titles

## 1.1.0
- Gradient fills for shapes; stacked bar and filled-area line charts; merged table cells
- PDF export has a selectable, searchable text layer
- Deck-wide footer and slide numbers; per-slide rehearsal targets with an over-time warning in presenter view
- Accessibility: landmarks on editor and presenter view (axe: zero issues on all tested screens)
- Robustness: crash-recovery screen, "new version available" prompt, warning when closing during an unsaved change,
  clearer messages for full or blocked browser storage, request for persistent storage

## 1.0.0
- First release: editor, presenting, presenter view, import/export (PDF, PNG, PPTX, HTML, JSON), password lock,
  autosave and version history, offline PWA.
